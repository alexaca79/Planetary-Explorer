## Current Documentation

The maintained entry point is [README.md](README.md). This general template
contains mock tools and is not a production MCP server. Its CPU-only local
experiment, client requirements and deployment blockers are documented there.

For real Planetary Explorer application deployment, use the
[deployment/resource guide](../../documentation/deployment.md), not the old
duplicated instructions. Do not treat sample results as satellite measurements
or enable public access solely because a health endpoint responds.
